# 🖥️ Terminal の起動

macOS や Linux では，Terminal（ターミナル）を使ってコマンドライン操作を行う．
以下の手順で起動する．

## macOS の場合

1. Spotlight 検索を開く（`Command + Space`）．
2. 「Terminal」と入力し，`Enter` キーを押す．

## Linux の場合

1. アプリケーションメニューを開く．
2. 「Terminal」または「端末」と入力し，選択する．
