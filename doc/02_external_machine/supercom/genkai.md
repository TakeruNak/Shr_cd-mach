# 九州大学 Genkai

> 📝 **（執筆予定）**

以下の項目をまとめる予定．

1. 利用者登録と SSH 公開鍵の登録
2. ログイン方法
3. 利用可能な計算ノードとキューの構成
4. ジョブスクリプトの書き方
5. 計算コード（OpenMX / Quantum ESPRESSO）の利用方法

それまでは公式の[利用手引き](https://www.cc.kyushu-u.ac.jp/scp/)を参照．
SSH 公開鍵の作り方そのものは，[SystemB へのログイン方法](./sec/systemb_login.md) と共通である．
