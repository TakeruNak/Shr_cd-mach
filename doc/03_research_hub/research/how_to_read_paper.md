# 論文読解プロセス：効率と本質の追求

## 【指針】論文読解とは「目的」に基づく情報の取捨選択である

全文を同じ密度で読むのではなく，**全体像（森）を捉えてから必要な詳細（木）を拾い，自身の研究へ落とし込む**．

```
1. Set the purpose --> 2. Macro reading (forest) --> 3. Micro reading (trees) --> 4. Apply to own research
```

---

## 1. 目的を定める

「この論文から何を学びたいか？」を先に決め，それを読む箇所の取捨選択の基準にする．全てを読む必要はない．

## 2. マクロ読解：構造と結論の把握

### 2.1 Abstract から骨組みを抜き出す

[研究デザイン](./how_to_consider.md) の要素に沿って，次を特定する．

| 要素 | 問い |
|---|---|
| **Surprising Fact** | 既存の常識を覆す驚愕の事実は何か |
| **Issue / RQ** | 解決すべき課題と，具体的な問いは何か |
| **Hypothesis** | 提示されている主張・仮説は何か |
| **Methodology** | 検証のためのアプローチは何か |

### 2.2 エビデンスと帰結の確認

* **図表（Figure / Table）を先に見る**：主張を裏付ける「最も強い証拠」を把握する．
* **Conclusion を確認する**：Abstract で示された問いがどう帰結したかを確認する．
* **References を確認する**：どの研究の流れを受け継ぎ，どの先行研究を拡張・批判しているかを見て，
  その論文（研究グループ）の業界内での立ち位置を把握する．

## 3. ミクロ読解：強弱をつけた精読

* **重点箇所の選定**：背景（Introduction）と考察（Discussion）を優先する．
* **手法（Method）のトリアージ**：既存手法ならスキップし，新規性・再現性が重要な場合のみ精読する．
* **パラグラフ・リーディング**：Topic Sentence（各段落の要旨）を中心に読み，詳細は必要に応じて読み飛ばす．

## 4. 知見の昇華：抽象と具象の往復

**ここが読解の目的地**である．論文を読む目的は知識の蓄積ではなく，**体系のどこが破綻しているかを探り当てること**にある．
「この論文が前提にしている体系は何か」「その体系はどこで綻びているか」を意識して読む．

* **具象 → 抽象（情報の抽出）**：個別の知見から拘束条件を外し，汎用的な概念や短文に言い換える．
* **抽象 → 具象（情報の適用）**：抽出した概念に別の変数を代入し，新たな対象への適用を思考実験する．
* **位置づけ**：§2.2 で把握した論文の立ち位置をもとに，自身の研究テーマとの相対的な位置を考える．
