# 並列計算ガイド

第一原理計算を実際に回すうえで，並列化の理解は避けて通れない．
本ガイドは，並列計算の基本概念と実際の使用例を通して，その理解を深めることを目的とする．

---

## 1. 2つの並列化：MPI と OpenMP

まず押さえるべきは，**プロセスとスレッドの違い**である．

| | MPI | OpenMP |
|---|---|---|
| 並列の単位 | プロセス | スレッド |
| メモリ空間 | **共有しない**（各プロセスが独立） | **共有する**（同一プロセス内） |
| 通信コスト | 明示的なメッセージ通信が必要 | メモリ共有のため小さい |
| スケール範囲 | 複数ノードにまたがれる | 原則1ノード内 |
| OpenMX での指定 | `mpirun -np <N>` | `openmx ... -nt <N>` |

> 💡 **イメージ**：計算機の中には複数の小さなパソコン（CPU コア）が入っている．
> 小さなパソコン同士に仕事を分けるのが MPI，1つの小さなパソコンの中で仕事を分けるのが OpenMP．

## 2. 並列数の決め方

全体で使うコア数は，おおよそ次の関係で決まる．

$$ N_{\rm MPI} \times N_{\rm OpenMP} = (\text{1ノードあたりのコア数}) \times N_{\rm Node} $$

たとえば物性研 SystemB は 1 ノードあたり 128 コアなので，4 ノードを使うなら
`-n 16`（MPI）× `--cpus-per-task=32`（OpenMP）= 512 = 128 × 4 と揃える．

> ⚠️ **並列数を上げれば速くなるとは限らない．**
> コア間・ノード間のデータ通信時間が増えるため，どこかで頭打ちになり，むしろ遅くなる．
> 本番の系で回す前に，小さい系で並列数を段階的に上げて実測し，効率の良い点を探すこと．

具体的なジョブスクリプトの例は
[Queue system (Slurm) の利用](../../02_external_machine/supercom/sec/systemb_slurm.md) を参照．
